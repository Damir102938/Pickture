# Pickture

_Pick (выбирать) + Picture (фильм)._

Android-приложение, где можно следить за новинками кино и сериалов и получать рекомендации по своему вкусу.
Данные берутся из [TMDB](https://www.themoviedb.org/). Всё хранится на телефоне, сервер и регистрация не нужны.

## Возможности

- **Новинки**: цифровые релизы фильмов, новые сериалы, сериалы в эфире, анонсы фильмов и сериалов на полгода вперёд, тренды недели.
  Отдельная полка «Новинки для вас» собирает свежие релизы, которые лучше всего совпадают со вкусом.
- **Оценки**: «Нравится», «Не моё», «Хочу посмотреть». На каждой карточке показан процент совпадения со вкусом.
- **Для вас**: персональные рекомендации с объяснением, например «Похоже на „Дюну“» или «Любимые жанры: фантастика».
- **Стартовый экран**: выбор любимых жанров и фильмов, чтобы рекомендации появились сразу. Его можно пропустить, пройти заново или
  отключить в настройках (переключатель «Учитывать в рекомендациях»).
- **Уведомления** (проверка дважды в сутки): выход фильма из «Хочу посмотреть» в кино и онлайн, новый сезон сериала,
  свежие релизы с совпадением от 80%.
- **Поиск** по фильмам и сериалам.
- **Трейлеры прямо в приложении**: встроенный плеер YouTube без перехода в приложение YouTube; при повороте телефона видео разворачивается на весь экран, ролики можно переключать.
- **Резервная копия**: в настройках можно сохранить оценки и списки в JSON-файл и восстановить их, в том числе прямо со стартового экрана после переустановки.

## Запуск

1. Получите бесплатный ключ: themoviedb.org → Settings → API. Подойдёт и «API Key», и «API Read Access Token».
2. Откройте `local.properties` в корне проекта и впишите ключ:
   ```properties
   TMDB_API_KEY=ваш_ключ
   ```
   Этот файл не попадает в git.
3. Откройте папку проекта в Android Studio и нажмите Run, либо соберите из консоли:
   ```bash
   ./gradlew installDebug
   ```

### Релизная сборка

Релиз подписывается своим ключом. Положите в корень проекта два файла, оба не попадают в git:
- `pickture-release.jks` — сам ключ;
- `keystore.properties`:
  ```properties
  storeFile=pickture-release.jks
  storePassword=...
  keyAlias=pickture
  keyPassword=...
  ```

Затем:
```bash
./gradlew assembleRelease
```
APK появится в `app/build/outputs/apk/release/`. Debug-сборка подписывается тем же ключом, поэтому обе ставятся друг поверх друга.
Если ключ потерять, обновить уже установленное приложение будет нельзя: придётся удалить его вместе с данными.

Если TMDB недоступен из вашей сети, включите VPN на телефоне или эмуляторе. Ещё можно указать свой прокси
в `local.properties` (`TMDB_API_URL`, `TMDB_IMAGE_URL`).

## Как устроены рекомендации

Код в `domain/TasteProfile.kt` и `domain/RecommendationEngine.kt`.

1. **Профиль вкуса.** Веса жанров считаются по лайкам, дизлайкам и стартовым жанрам. Сериальные жанры TMDB
   приводятся к «киношным», чтобы фильмы и сериалы учитывались вместе. Из деталей понравившихся тайтлов
   дополнительно сохраняются ключевые слова, актёры и режиссёры.
2. **Кандидаты.** Это «рекомендации TMDB» к последним 10 лайкам, подборки по любимым жанрам, темам
   и людям, а также свежие релизы.
3. **Оценка кандидата:**
   `0.42·жанры + 0.30·«сколько лайков на него указывают» + 0.16·рейтинг + 0.12·свежесть − 0.40·сходство с дизлайками`.
   Уже оценённое и отложенное в рекомендации не попадает.

## Стек

Kotlin, Jetpack Compose (Material 3), Navigation, Room, DataStore, WorkManager, Retrofit + kotlinx.serialization, Coil,
android-youtube-player (встроенный плеер YouTube), SplashScreen API. minSdk 26, compileSdk 35, targetSdk 34.

## Структура

```
app/src/main/java/com/moviepicker/
├── data/            TMDB API, Room, настройки, репозиторий
├── domain/          модели, жанры, профиль вкуса, движок рекомендаций
├── work/            фоновая проверка релизов и уведомления
└── ui/              экраны: новинки, раздел, детали, для вас, поиск, мои списки, настройки, онбординг
```
