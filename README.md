# Pickture

_Pick (выбирать) + Picture (фильм)._

Приложение для Android, Windows и iPhone, где можно следить за новинками кино и сериалов и получать рекомендации по своему вкусу.
Данные берутся из [TMDB](https://www.themoviedb.org/). Всё хранится на устройстве, сервер и регистрация не нужны.

## Скачать

Свежие версии лежат в [релизах](https://github.com/Damir102938/Pickture/releases/latest):
- **Android:** `Pickture-<версия>.apk`. Откройте файл на телефоне и разрешите установку.
- **Windows:** `Pickture-desktop-<версия>-windows.zip`. Распакуйте архив и запустите `Pickture.exe`, Java устанавливать не нужно.

При первом запуске приложение попросит личный ключ TMDB. Он бесплатный, а ссылки на регистрацию и страницу
ключей есть прямо на экране ввода. Один и тот же файл подходит всем: каждый вводит свой ключ.

**iPhone:** веб-приложение, которое ставится на экран «Домой», см. раздел [iPhone](#iphone) ниже.

Android-версия при запуске сама проверяет релизы на GitHub, предлагает обновиться и ставит новую версию поверх старой.
Версия для ПК показывает уведомление о новой версии и ссылку на архив.

## Возможности

- **Новинки**: цифровые релизы фильмов, новые сериалы, сериалы в эфире, анонсы фильмов и сериалов на полгода вперёд, тренды недели.
  Отдельная полка «Новинки для вас» собирает свежие релизы, которые лучше всего совпадают со вкусом.
- **Оценки**: «Нравится», «Не моё», «Хочу посмотреть». На каждой карточке показан процент совпадения со вкусом.
- **Для вас**: персональные рекомендации на двух вкладках, «Фильмы» и «Сериалы», с объяснением,
  например «Похоже на „Дюну“» или «Любимые жанры: фантастика».
- **Стартовый экран**: выбор любимых жанров и фильмов, чтобы рекомендации появились сразу. Его можно пропустить,
  пройти заново или отключить в настройках.
- **Уведомления** (Android, дважды в сутки): выход фильма из «Хочу посмотреть» в кино и онлайн, новый сезон сериала,
  свежие релизы с совпадением от 80%.
- **Трейлеры прямо в приложении** (Android): встроенный плеер YouTube, при повороте телефона видео разворачивается на весь экран.
- **Резервная копия**: оценки и списки сохраняются в JSON-файл. Формат общий для Android и ПК, так что оценки можно перенести между устройствами.
- **Поиск** по фильмам и сериалам.

## iPhone

Для iPhone есть веб-версия (PWA) из папки `web/`. Она повторяет Android-приложение: ленту новинок, «Для вас»,
поиск, списки, карточки фильмов, трейлеры и настройки. Mac и аккаунт разработчика Apple не нужны.

**Как установить.** Откройте сайт приложения в **Safari** (адрес появится после включения GitHub Pages, см. ниже),
нажмите «Поделиться» → «На экран Домой». Pickture откроется на весь экран, как обычное приложение.
Без интернета оно тоже запускается: показывает сохранённые ленту, подборку и списки.

**Где хранятся данные.** Ключ TMDB, лайки, дизлайки, «Хочу посмотреть», настройки и последние рекомендации
лежат в памяти браузера на телефоне (IndexedDB с копией в localStorage) и не пропадают после закрытия приложения.
У значка на экране «Домой» своё хранилище, отдельное от Safari: то, что отмечено в Safari, туда не попадёт.
Если удалить значок, данные удалятся вместе с ним, поэтому иногда сохраняйте резервную копию:
Настройки → «Сохранить в файл». Файл тот же, что на Android и ПК, так что оценки можно переносить между устройствами.

**Чего нет по сравнению с Android:** уведомлений о релизах (для веб-push нужен сервер) и автоповорота плеера:
трейлер играет во встроенном плеере YouTube, а на весь экран его разворачивает кнопка плеера.

### Сборка и проверка веб-версии

Нужен Node.js 20.19+ или 22.12+.

```bash
cd web
npm install
npm run dev       # разработка: http://localhost:5173 (и по адресу компьютера в локальной сети)
npm run build     # статические файлы в web/dist
npm run preview   # собранная версия с service worker: http://localhost:4173
```

Для локальной проверки ключ можно не вводить: на экране ключа появится кнопка «Использовать ключ из local.properties».
Ключ берётся из `TMDB_API_KEY` в `local.properties` или из переменной `PICKTURE_TMDB_KEY`. Dev- и preview-сервер
отдают его только запросам с этого же компьютера, в сборку он не попадает. Для git worktree путь к файлу задаёт
`PICKTURE_LOCAL_PROPERTIES`.

Установить PWA на iPhone можно только по HTTPS, поэтому для телефона нужна публикация.

### Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` собирает `web/` с `base: /Pickture/` и выкладывает результат на GitHub Pages.
Он запускается только вручную. Чтобы включить:

1. Слейте ветку с веб-версией в `main`.
2. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Actions → «Web (GitHub Pages)» → **Run workflow**.

Сайт появится по адресу `https://damir102938.github.io/Pickture/`. Чтобы публиковать автоматически при каждом
изменении `web/` в `main`, раскомментируйте блок `push` в workflow. Приложение на телефоне подхватывает новую
версию само и предлагает перезапуститься.

Иконки (`web/public/icons`) рисует `python web/scripts/make_icons.py web/public/icons` (нужен Pillow).
Геометрия та же, что у `ic_launcher_*.xml`.

## Сборка из исходников

Нужны JDK 17 и Android SDK (Android Studio подойдёт).

```bash
./gradlew :app:assembleDebug              # Android, debug
./gradlew :app:assembleRelease            # Android, релиз (нужен ключ подписи, см. ниже)
./gradlew :desktop:run                    # запустить версию для ПК
./gradlew :desktop:createDistributable    # Pickture.exe + Java в desktop/build/compose/binaries/main/app/
```

Версия приложения задаётся в `gradle.properties` (`pickture.version`, `pickture.versionCode`) и общая для обеих платформ.

Для удобства разработки ключ TMDB можно не вводить в приложении:
- **Android (debug):** строка `TMDB_API_KEY=...` в `local.properties`. В релизную сборку ключ не попадает.
- **ПК:** переменная окружения `PICKTURE_TMDB_KEY`. `PICKTURE_DATA_DIR` задаёт отдельную папку данных для тестов.

Если TMDB недоступен из вашей сети, включите VPN. Для Android ещё можно указать свой прокси в `local.properties`
(`TMDB_API_URL`, `TMDB_IMAGE_URL`).

### Подпись Android-релиза

Положите в корень проекта два файла, оба не попадают в git:
- `pickture-release.jks` — сам ключ;
- `keystore.properties`:
  ```properties
  storeFile=pickture-release.jks
  storePassword=...
  keyAlias=pickture
  keyPassword=...
  ```

Debug-сборка подписывается тем же ключом, поэтому обе ставятся друг поверх друга.
Если ключ потерять, обновить уже установленное приложение будет нельзя: придётся удалить его вместе с данными.

### Выпуск новой версии

1. Поднимите `pickture.version` и `pickture.versionCode` в `gradle.properties`.
2. Соберите `:app:assembleRelease` и `:desktop:createDistributable`, а затем запакуйте папку `Pickture` в zip.
3. Создайте релиз с тегом `v<версия>` и приложите `Pickture-<версия>.apk` и `Pickture-desktop-<версия>-windows.zip`.
   Приложения находят обновление по последнему релизу и по этим именам файлов.

## Как устроены рекомендации

Код в `core/.../domain/TasteProfile.kt` и `core/.../domain/RecommendationEngine.kt`, а для iPhone есть точный
порт на TypeScript в `web/src/core/taste.ts` и `web/src/core/engine.ts`.

1. **Профиль вкуса.** Веса жанров считаются по лайкам, дизлайкам и стартовым жанрам. Сериальные жанры TMDB
   приводятся к «киношным», чтобы фильмы и сериалы учитывались вместе. Из деталей понравившихся тайтлов
   дополнительно сохраняются ключевые слова, актёры и режиссёры.
2. **Кандидаты.** Это «рекомендации TMDB» к последним 10 лайкам, подборки по любимым жанрам, темам
   и людям, а также свежие релизы.
3. **Оценка кандидата:**
   `0.42·жанры + 0.30·«сколько лайков на него указывают» + 0.16·рейтинг + 0.12·свежесть − 0.40·сходство с дизлайками`.
   Лучшие фильмы и лучшие сериалы отбираются отдельно. Уже оценённое и отложенное в рекомендации не попадает.

## Структура

```
core/      общая логика на Kotlin/JVM: TMDB, рекомендации, настройки, резервные копии, проверка обновлений
app/       Android: Jetpack Compose, Room, WorkManager, уведомления, плеер трейлеров, установка обновлений
desktop/   Windows: Compose Desktop, хранение в JSON-файле, упаковка в Pickture.exe
web/       iPhone (PWA): Vite + TypeScript + Preact, IndexedDB, service worker
```

**Стек:** Kotlin, Jetpack Compose и Compose Desktop (Material 3), Room, DataStore, WorkManager, Retrofit + OkHttp +
kotlinx.serialization, Coil, android-youtube-player. Android: minSdk 26, compileSdk 35, targetSdk 34.
